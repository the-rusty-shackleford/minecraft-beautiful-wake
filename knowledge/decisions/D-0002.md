# D-0002 — The booth makes its own world, and clears it every run

**Decision**: The photo booth creates a fresh flat world through
`WorldOpenFlows.createFreshLevel` at the title screen, digs a pool into it
from the integrated server, spawns and drives its own boat and cow, drops
its own items, and asks the client to re-render all terrain before it
photographs. The Gradle task that prepares the booth is never up to date,
so the save is deleted before every run.

**Why**: A client-only mod has no gametest server; the sibling mods' booth
quick-plays a save a gametest run left behind, and this mod has none. A
world made in code is repeatable and needs no fixture. Two things bit on
the way: `createFreshLevel` reopens an existing folder of the same name
(the second run had two boats, the eighth seven cows), and a pool dug after
the client already held the chunks left every section over it stale under
a software renderer, which rebuilds slowly, so `allChanged()` and a hold
of six seconds precede the first photo. Minecraft's yaw is 0 south, 90
west, -90 east; the first boat drove off the pool.

**Links**: `src/gametest/.../WakeBooth.java`, `build.gradle` (`prepareBooth`).
